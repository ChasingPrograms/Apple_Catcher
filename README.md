# 🍎 Apple Catcher

A simple 2D game built in Java where you move a basket left and right to catch apples falling from the sky.

This is my first personal Java project, built to strengthen my OOP and game-loop fundamentals after graduating with a BA in Computer Science.

## 🎮 How to Run

1. Clone the repo
2. Open in your IDE (built using VS Code)
3. Run `Main.java`
4. Use ⬅️ / ➡️ or **A** / **D** to move the catcher

## 🛠️ Tech Used

- Java
- Java Swing (`JFrame`, `JPanel`)
- Basic multithreading (game loop)
